# Contributing to Juno

Thank you for your interest in **Juno**! 💛  
Juno is a web-based reading environment for Ancient Greek and Latin texts, designed to help learners develop morphological skills through active annotation and instant feedback.

At the moment, Juno is **primarily a solo-developed research project** and is still evolving. While the project is not yet in a state that supports external code contributions, this document exists to:

- Document development practices and future collaboration plans
- Make it easy for others to engage through feedback, discussion, and issues

As the project stabilizes, this file will expand to include full contributor setup instructions and workflows.

---  
## Project Status

Juno is currently:

- Actively under development as a **master’s thesis project**
- Undergoing architectural iteration and feature refinement
- Preparing for **student user testing in Spring 2026**

Because of this, some areas of the codebase may be experimental, sparsely documented, or subject to refactoring.
You can find the live version of the project at https://juno-reader.vercel.app/

---

## How You Can Contribute Now

Contributions are very welcome in the following forms:

- 🐛 **Bug reports** (especially UI or annotation edge cases)
- 💡 **Feature suggestions**, particularly pedagogically motivated ones
- 🧠 **Discussion** around morphology, syntax, or treebank use
- 📝 **Feedback** from instructors or students using Greek or Latin texts

If you’re interested in contributing code in the future, feel free to open an issue to discuss ideas, or star the repository and check back after February 2026.
